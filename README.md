# Tugx

منصة SaaS عربية تساعد الأنشطة التجارية ومقدمي الخدمات على إنشاء صفحة أعمال، إدارة محادثات WhatsApp، وإطلاق حملات متوافقة مع سياسات WhatsApp.

## النسخة الحالية

واجهة أولية قابلة للفتح مباشرة من `index.html`، وتشمل:

- لوحة مؤشرات للنشاط.
- إدارة صفحة الأعمال مع معاينة فورية.
- صندوق وارد WhatsApp تجريبي.
- حملات ورسائل جماعية مع تنبيه للموافقة المسبقة.
- إعدادات أولية لمساعد Tugx AI.

## ما سنبنيه بعد رفعه إلى GitHub

1. تطبيق Next.js وواجهة API آمنة.
2. تسجيل دخول وربط المؤسسات والمستخدمين.
3. قاعدة بيانات PostgreSQL عبر Supabase.
4. تكامل رسمي مع WhatsApp Business Platform (Cloud API).
5. اشتراكات ودفع عبر بوابة مناسبة للسوق المستهدف.

## التشغيل المؤقت

افتح `index.html` في أي متصفح. لا يتطلب ذلك تثبيتًا.

## ملاحظة امتثال WhatsApp

الحملات تستهدف فقط العملاء ذوي الموافقة الصريحة (opt-in)، وتستخدم القوالب التي تعتمدها Meta خارج نافذة المحادثة المسموح بها.
