# Tugx

منصة SaaS عربية لإدارة WhatsApp للأعمال: المحادثات، العملاء، الحملات المتوافقة مع سياسات Meta، ومساعد توجيكس AI.

## النسخة الحالية

واجهة أولية قابلة للفتح مباشرة من `index.html`، وتشمل:

- لوحة مؤشرات للنشاط.
- صندوق وارد WhatsApp تجريبي.
- حملات ورسائل جماعية مع تنبيه للموافقة المسبقة.
- إعدادات أولية لمساعد توجيهك AI.

## المرحلة B — Backend

بدأ تنفيذ الأساس الفعلي داخل مجلد `backend`: خادم Node.js، مخطط Prisma متعدد مساحات العمل، Webhook موثّق لواتساب، وRedis/BullMQ لطوابير الحملات. راجع `backend/README.md` للتشغيل والنشر.

## المراحل التالية

1. Backend على Render وقاعدة بيانات مُدارة عبر Aiven، مع Redis للطوابير.
2. تكامل رسمي مع WhatsApp Business Cloud API وWebhook موثّق.
3. جهات اتصال وشرائح وحملات ملتزمة بالموافقة المسبقة.
4. مساعد توجيهك AI مع RAG وCloudflare R2 وبوابة دفع تلقائية.
5. ربط سلة وزد، ثم منصات الإعلانات والردود الموحدة.

## التشغيل المؤقت

افتح `index.html` في أي متصفح. لا يتطلب ذلك تثبيتًا.

## ملاحظة امتثال WhatsApp

الحملات تستهدف فقط العملاء ذوي الموافقة الصريحة (opt-in)، وتستخدم القوالب التي تعتمدها Meta خارج نافذة المحادثة المسموح بها.
